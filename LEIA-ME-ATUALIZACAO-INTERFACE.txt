ATUALIZAÇÃO DA ACADEMIA DOS VALIDADORES

Alterações aplicadas:
- Hero redesenhado com identidade visual imersiva.
- Avatar do Gui criado a partir das características da foto enviada.
- Gui integrado como assistente virtual flutuante.
- Marca Academia dos Validadores em maior destaque.
- Dashboard com novos indicadores, animações e jornada visual.
- Login, páginas internas, trilhas e certificado padronizados.
- Layout responsivo para desktop, tablet e celular.
- Todos os módulos temporariamente desbloqueados durante a finalização da trilha.
- Certificado continua condicionado à conclusão dos sete módulos.

PUBLICAÇÃO
1. Faça uma cópia de segurança da pasta atual.
2. Copie o conteúdo desta pasta para o projeto local.
3. Confirme a substituição dos arquivos.
4. No terminal da pasta do projeto, execute:
   git add .
   git commit -m "Atualização visual e liberação temporária das trilhas"
   git push

Os módulos foram liberados apenas para acesso. O progresso continua sendo registrado normalmente.
